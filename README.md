# Student Attendance Tracker

A front-end web development prototype using HTML, CSS, JavaScript and browser Local Storage.

## Features
- Add student names and roll numbers
- Reject duplicate roll numbers
- Mark attendance as Present or Absent
- Calculate attendance percentages
- Display dashboard totals
- Store demo data in the current browser with Local Storage

## Run the project
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern web browser.

## Important limitations
This is a learning prototype, not a secure institutional system. Local Storage is limited to one browser and does not synchronize across users or devices. Real deployment requires authentication, server-side validation, and a shared database.
